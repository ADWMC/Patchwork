## 1.0.0（2026-11-04）

- 修复在 DSH 0.2.1 及更新宿主上安装后宿主包版本冲突的隐患：`@deepseek-ai/dsh-home-paths` 改为 peer 依赖，由目标 DSH 提供宿主同版本；发布包不再携带 0.2.0-rc.2 副本。重新安装包即可，浏览器数据与授权状态不变。

- 环境管理增加搜索和身份类型筛选，切换前对照当前与目标的内核、语言、时区、视口、DPR 和存储设置；切换、清登录及删除先在面板内确认，编辑使用打开时的配置版本，取消不改变环境。资源管理增加状态摘要、保护原因与手动回收确认，说明网址恢复和表单丢失边界。确认区自动滚动进入查看范围；沿用 DSH token 与宿主控件，不接管宿主浏览器。

- 原生指纹启动显式传入配置的像素比，修复部分种子覆盖 DPR 而导致配置、渲染与环境自检不一致的问题；隔离实测覆盖两个随机身份的 DPR 1 / 2。

- 可选内核的安装目录与会话私有环境数据目录可分别传入；状态检查、指纹切换预检、启动和录像组件共用安装目录，登录态仍写入本会话目录。隔离验收不需要复制内核或复用其他会话数据。

- 浏览器后验不匹配、错误和无进展回执按失败汇入 Patchwork 证据/Incident；单独浏览器 UI 动作也可追溯，仅当前已授权 Patchwork 会话接收。
- 正常停用先保存加密登录态再撤销；保存期间旧工具不能重建会话。安全撤权保持立即取消，不保存被撤销的迟到状态。

- 组件安装器的 ZIP 读取依赖 `yauzl` 升至 `3.2.1`，修复畸形 NTFS 扩展时间戳可能触发越界异常的问题（GHSA-gmq8-994r-jv83）；安装及校验流程不变。

- 人工输入不再逐字执行 Agent 的前后 ARIA 验收及完整 status；轻量输入带序号去重、有界合并与焦点／标签／文档校验，未知结果不自动重放。普通操作仅使观察过期，不再停止同页画面流。
- 宿主支持升级路由时使用一次性短时票据建立二进制 WebSocket，帧按实际显示确认，积压时保留最新帧；旧宿主回退到优化后的 SSE，再回退 JPEG。静态页不再因 3 秒没有新画面而重连；像素更新独立于工具栏渲染。
- 补齐真实鼠标按下／移动／释放、拖拽、双击、横向滚动和失焦释放；通过可编辑输入代理处理输入法组合与主动粘贴。增加主动复制选中文字、停止加载、适应／100%／150%画面缩放和可退出的扩大视图。
- Agent 新增紧凑交互快照与真实元素引用、限长 read、条件 wait、hover、scrollTo，以及最多 8 步 fill／check／selectOption 批处理。引用过期或元素身份变化时拒绝；批处理保留部分进展，不自动重放。
- 通过按实际 Agent 实例绑定的可选能力桥接 Patchwork 检索。显式浏览器检索使用同一内核内临时空登录上下文，检查范围／robots／公网 DNS，按校验地址建立连接，限制请求／流量／时间，只允许 GET/HEAD；用户接管可立即取消，不抢占可见标签。Camoufox 与 SOCKS 检索代理暂不支持，正常手动浏览不受此限制。
- 补充固定 commit 的 ZCode／agent-browser／browser-use／Playwright MCP 源码研究、隔离 DSH 工具调用与公网抓取验收，以及浅深色／窄栏视觉检查。100 次本地输入到显示 P95 为 37.6 ms、滚动 28.1 FPS，仅代表文档所述单机样本；测试口径与未覆盖项见[执行记录](docs/performance-interaction-plan-2026-11-01.md#执行记录2026-11-01)。

- 新增独立安装的 AliasMode 原生指纹内核入口，固定 Windows x64 发布与资产校验；面板区分“新增原生指纹”和旧 JS 样本路径，显示安装状态，不随主包或面板打开自动下载。安装命令与兼容边界见[原生指纹记录](docs/native-fingerprint-2026-11-01.md)。
- 原生身份按进程固定种子，编辑区域设置保留身份，更换创建独立空登录环境，点击“使用”才重启当前会话内核。启动失败尝试恢复原身份、网址与登录；撤权／取消释放晚到进程，其他会话保持运行。表单与页面内存不保留；已有档案改内核或身份类型需新建。
- 环境自检新增 Client Hints 核对：比较 JS 与本地实际收到的低／高熵请求头，并核对 Chromium 版本；未收到的字段标记待确认。仍不对出口 IP、TLS 或站点反检测通过作保证。
- 浏览器自身界面复用 DSH 的 Button、Input、Menu、Switch、Tooltip 和 DisclosureRow；环境选择改为宿主菜单，登录与自动回收改为宿主开关，移除原生 select 弹层、details 默认交互和 title 系统提示。圆角、阴影、颜色和字体统一使用宿主 token，多行标注保留文本编辑语义。
- 修复元素选中后仍短暂显示拾取状态的问题：点击选定时立即退出检查，截图与画面刷新完成后显示说明，不因网络或刷新时序重复拾取。
- 页面标注改为“检查元素”式拾取：悬停真实 DOM 显示高亮、标签／id／class、尺寸及内容／内边距范围，点击后退出拾取并聚焦说明；保留拖动框选、Space 临时操作和 Esc 退出。高亮不注入网页，悬停不截图或写 trace，导航／撤权／旧响应会使检查失效；开放 Shadow DOM 可检查，iframe 目前止于边界。
- 将“指纹”入口放到标签栏右侧；环境管理显示实际内核、设备参数／指纹 ID 和样本主版本，不兼容时明确禁止启用。
- 新增用户面板的“更换设备参数／更换指纹”：生成不同参数的独立新环境，不复制旧登录，保留源环境与当前页面；用户再点击“使用”切换。生成失败、旧 revision 和外会话引用均拒绝写入；完整指纹在当前系统内核中的实际注入仍受版本兼容限制。
- 修复设备／完整指纹模式在侧栏导航时被自动适配覆盖屏幕参数的问题；原生模式继续自动适配，用户显式调整视口的影响与限制见指纹更换记录。
- 新增页面标注：点击元素、拖动框选、编号与说明、按需 PNG 裁图、Space 临时操作网页和 Esc 退出。草稿私有，用户显式提交后仅当前已授权 Agent 可读；支持原生当前会话消息桥和发送失败重试，不自动恢复 Agent 控制。
- 新增仅在已授权 Agent 内注册的 `browser-workspace` 按需技能及 GUI 验收／操作契约参考；新增精确 URL 复用 `open`、确定开关状态 `check`、`selectOption` 与快照 option value，面板内支持 Ctrl/Cmd+L/T/W/R。调研与后续优先级见[融合记录](docs/experience-design-2026-11-01.md)。
- 修复技能注册失败后的工具残留与授权清理；撤权发生于异步浏览器请求期间时统一返回 403；新草稿清理旧发送提示，失效标注不能重新提交或继续发送。
- 按用户提供的浏览器框架截图调整独立侧栏：顶部标签页与新建入口，下方前进／后退／刷新和胶囊地址栏；环境、资源、检查与停用移入更多菜单。跟随宿主浅深色，适配窄栏，菜单支持键盘与 Escape，底栏保留接管／恢复 Agent 和录像状态。
- 修复通过 Windows 原生 pnpm 执行发布预检时，误将 `pnpm-native.exe` 当作 npm JavaScript CLI 的问题。
- 从 `@patchwork/coding-agent` 拆出浏览器运行时、独立侧栏、会话环境、资源管理、画面流和组件安装器，主包不再携带浏览器代码或相关运行时依赖。
- 任意模式可在独立“浏览器”侧栏显式授权当前会话；工具按 Agent 原生作用域注册，切换模式或停用时撤权。
- 增加基于 DOM 观察的语义定位与观察代次检查；继续通过 DSH 画面流显示真实浏览器，不使用 Electron 原生嵌入。
- 新命令为 `patchwork-browser-components`；旧浏览器配置不再由主包管理，部署资源策略移至本包配置。未发布到 npm。
