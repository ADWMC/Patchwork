# 独立浏览器框架调整

日期：2026-11-01。用户确认采用截图上方的标签页、前进后退、刷新与地址栏布局。

## 设计与实现

本次修改位于 `packages/browser`，保持独立可选插件。顶端为标签页、关闭和新建按钮；第二层为前进／后退／刷新、胶囊地址栏、适配宽度和更多菜单。沿用 DSH 颜色、字体与主题，不固定深色。为侧栏压缩到约 100–110 px 的导航高度，网页画面直接连接工具栏，移除额外标题和嵌套卡片留白。

环境、资源、检查与记录以及停用授权移入更多菜单，扩展面板一次只显示一个。底栏始终提供控制权状态、接管／恢复 Agent，录像启用时显示记录状态。截图中的 Annotate 和其他宿主功能不属于此次确认范围，未添加装饰性假按钮。

`BrowserChrome.jsx` 负责标签页、导航和键盘菜单；`BrowserPanel.jsx` 保留真实浏览器的动作队列、鉴权画面流、输入身份校验和用户接管。切换、停用、会话隔离继续使用既有权限机制。原生会话中启用浏览器仍需用户明确授权。

## 验证

- 全仓回归 300 项通过，0 失败、0 跳过。
- 私有 Edge 实际运行：地址栏导航、新建／选择／关闭标签、前后退、刷新、菜单 Escape／焦点、环境面板与停用；9 次原生工具调用包含过期观察、歧义和用户接管的拒绝验证。
- 1264 px 深色、900 px 浅色、380 px 浅色、320 px 深色无水平溢出；确认标签页最先出现、导航紧随其后、真实画面足够可见，适配后校验图像原始宽度而非 CSS 缩放宽度。
- 这次使用真实 DSH 注册表、测试 Agent 和隔离 HTTP／会话投影夹具；未运行完整 DSH App、未请求模型，也未操作用户浏览器或主 DSH。
