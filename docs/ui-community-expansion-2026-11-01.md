# 功能界面社区调研与扩充执行

日期：2026-11-01。范围：Patchwork 主包与独立可选浏览器包。本文记录本轮调研、实施选择和验收；已有调研结论继续保留，不以文档数量代替功能完成。

## 范围与设计约束

逐项覆盖任务总览、Superagent 队列、运行机制与技能、工具证据、信息检索、记忆、受控改进、日志、设置，以及独立浏览器的标签、授权、环境与资源管理。

所有视觉与交互沿用 DSH 控件、字体、圆角与浅暗主题 token；按侧栏优先设计，再适配较宽面板。优先改善信息层级、筛选和详情，不添加虚构指标、无后端按钮、默认后台任务或跨会话数据。浏览器保持可选包，禁止主包静态依赖浏览器运行时。测试使用独立临时 DSH_HOME 与浏览器进程，不修改主 DSH。

## 执行阶段

1. 复用现有 ZCode、OpenClaude、OpenDesign、记忆与检索调研，补查社区的实际源码和界面资源，固定提交与阅读路径。
2. 按功能列出问题、采用的交互、数据依赖和退出条件；优先复用当前真实路由与状态。
3. 分批实现共用浏览结构与主包页面，再改善可选浏览器的状态和管理入口；保持危险操作的确认、版本校验与会话隔离。
4. 更新中文/英文说明、更新日志与发布文件；运行回归和独立界面验收，记录仍未实现的边界。

没有另起一套脱离已有结论的设计。浏览器沿用 [ZCode 研究](zcode-browser-research-2026-11-01.md)与 [ZCode / OpenClaude 提示词研究](zcode-openclaude-prompt-engineering-research-2026-10-31.md)中的会话所有权和操作边界；视觉遵守已有 [Web UI 技能审查](web-ui-skill-community-review-2026-10-31.md)，取 OpenDesign 的判断方法而不是照抄皮肤；改进继续遵守[用户体验改进宗旨](product-experience-evolution-plan-2026-10-31.md)，记忆管理继续遵守[版本、范围和召回规则](memory-management-2026-11-01.md)。

### 现有功能保持接入

这不是重建一套演示面板。主控接纳、任务撤回、记忆增删改查、隔离实验、改进回滚、日志导出和设置保存均保留真实路由。浏览器导航、标签、接管、画面流、输入、检查元素标注、截图、录像、文件传输、环境自检和组件 CLI 继续使用已有实现；本轮不把这些历史功能重新声称为新增。

组件安装器目前没有 Web 安装路由，界面只提示安装状态和真实 CLI 命令，不添加无后端的下载按钮。没有实现的跨会话搜索、记忆自动注入、费用趋势、模型质量评分、工作流画布、任意 DevTools 编辑仍不提供。

## 布局与交互契约

- 沿用 DSH `Button / Input / Menu / Switch / SegmentedTabs / DisclosureRow` 和现有 token，不使用原生 select、confirm 或 alert。整体卡片保持克制，筛选与统计不用再套一层大卡片。
- 面板宽度达到 760px 才启用列表 / 详情双列；侧栏中为单列，列表保持有界滚动。验收覆盖 1080、520、360px 面板，浅 / 暗主题各 9 个功能界面。
- 状态颜色仅辅助识别，仍有文字和 `aria-pressed`。所有搜索、筛选和操作都有可识别名称；长路径和错误码可换行。
- 页面描述解释范围，主要操作在详情中。破坏性操作用界面内确认，保留取消路径；不使用系统浏览器弹窗。
- 搜索只筛选当前预览或明确分页范围，不默默启动网络请求。分页与搜索变化重置来源选择，避免详情对应不可见条目。
- 会话切换与撤权仍清空原会话数据与浏览器像素；普通 Agent 不能读取 Patchwork 状态，查看目录不读取技能正文。

### 保留的失败与限制

最终同版本浏览器复测前，有一轮在 4 秒期限内没有观察到预期显示像素，报 `Input-to-display timed out`；当时控制台无错误、二进制连接未断开，当前信息不足以确认原因。没有放宽期限或修改通过阈值；保留失败报告哈希与传输计数，见证据快照中的 validation。相同源码复跑通过，不据此宣称已证明长期无卡顿。

早期界面验收还发现环境对照 grid 被高优先级 flex 样式覆盖、确认区出现在滚动区域下方，以及测试驱动绕过 Cordis schema 导致默认配置缺失。前两项已修正样式和确认区滚动；测试驱动显式传入已发布默认值，保留数组配置等值不产生脏草稿的断言。未用删除断言或虚构默认运行结果掩盖问题。

UI 使用真实 DSH 控件与带 token 的 HTTP 路由；主控派发是明确的可复核 fixture，不进行模型质量评估。检索列表、分页和引用使用显式 native-ledger fixture，不代表本轮运行了公网搜索。浏览器专项使用独立原生内核进程和独立 profile，真实性能数据只适用于受控页面和本机环境，不能据此声称优于 ZCode。
