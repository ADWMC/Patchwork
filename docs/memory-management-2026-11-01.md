# 记忆详细管理

入口：当前会话切换到 **Patchwork → 证据 → 记忆**。本页只管理当前授权范围内的记录，不把整页正文发送给模型。包版本仍为 0.2.0，以下属于未发布改动。

## 查找与查看

- 默认范围为“本会话私有”；可显式切到“当前项目共享”或两者。
- 搜索标题、正文、类型或适用条件，按待确认、已确认、历史、已遗忘及有效性筛选。
- 每页 20 条，前后翻页；配额与分类计数按当前所选范围计算，搜索结果数另行显示。管理接口单次最多 50 条，不以状态快照最近 200 条为全部历史。
- “查看详情”显示完整正文、条件、类型、来源会话、观察/确认时间、召回资格和版本；打开后滚动到详情。
- “来源与操作记录”保留最近 20 次状态操作；“内容版本历史”列出最近 50 个关联版本，更早记录仍可搜索翻页查看。它不是不可变的外部审计日志。

## 新增与修订

1. 点击“新增记忆”，填写标题、正文、适用条件和类型，选择保存范围。标题最多 256、正文 4000、条件 512、类型 64 字符；疑似凭据等敏感值拒绝保存。
2. “保存提案”只创建 proposed，不参与召回。检查内容后“确认”，才成为 active。
3. 在详情点击“修订记忆”，保存成新的待确认版本；原版本继续按原来的有效性参与或暂停召回。
4. 新修订确认前显示将替换的记录；确认后旧版本保留为 superseded，不再召回。若修订基底已被改动、替代或遗忘，旧提案拒绝确认，需要重新核对。

正文内容版本以 **v1、v2** 表示；**r** 是数据库状态变更修订号，用于并发检查。暂停、确认、遗忘会改变 r，不代表正文产生新版本。

修订保留原范围。需要由私有改为共享，或由共享转为私有时，可从详情“以此内容新建提案”，核对新范围再独立确认。该动作不会撤销原记录。

适用条件是给 Agent 核对的说明，不是自动运行的条件表达式，也不是权限授予。保存的记忆不能替代当前用户授权。

## 控制召回

| 状态与有效性 | 实际行为 |
| --- | --- |
| 待确认 proposed | 可查看、编辑或丢弃，不召回 |
| 已确认 active + 已核实 fresh | 可按需召回 |
| active + 暂停 stale / 冲突 conflicted / 过期 expired | 保留正文，停止召回；核实后可恢复 |
| 历史 superseded | 可查看、导出或遗忘，不召回 |
| 已遗忘 revoked | 已撤销；仍可查看保留的历史，不召回 |

“暂停召回”和“恢复召回”改变真实召回资格；详情还可标记冲突或过期。恢复只改变当前 active 的有效性。旧内容需要重新使用时，必须新建提案并确认，不直接复活历史或已遗忘记录。

自动记忆注入保持关闭。Agent 的 `list` 单次最多 5 条元数据，不含正文和来源历史；`inspect` 按明确 ID 读一条；`recall` 单次最多 5 条 active + fresh 正文，已确认的召回策略可进一步缩小上限。管理页读过某条记忆不表示已经把它给模型。

## 私有与项目共享

会话私有记录只对拥有该记录的 Patchwork 会话可见。项目按规范化工作目录隔离；项目共享需要明确选择与确认，其他 Patchwork 会话也须显式 includeProject 才能召回，不自动推送到其他对话。普通 Agent 无权使用这些接口。

共享记忆的确认、暂停、恢复或遗忘会影响同项目后续显式读取它的会话，界面会额外说明影响范围。共享不是跨用户访问控制系统，也不取代主机账户或文件权限。

## 导出与遗忘

- 选择当前页的记录，再“导出所选”：下载 JSON，含所选正文及记录元数据，不发送给模型。它不是全库备份，也未实现导入恢复。
- “遗忘所选”在确认后整批执行；一次最多 50 个 ID，管理页每页最多选 20 条。所有 ID、作用域与 revision 均通过才提交，任一失败不会部分遗忘。
- **遗忘是逻辑撤销，不是物理擦除。** 停止召回、失效旧引用，但保留正文历史、撤销记录和磁盘备份；已输出到对话或用户下载的文件无法追溯清除。

每个 namespace 最多 200 条未撤销的保存版本，待确认和历史也占配额。触顶时显式提示，可丢弃无用提案或遗忘不再需要的版本；系统不自动淘汰别的会话记忆。遗忘后仍保留磁盘历史，因此配额不是磁盘大小上限。

## 并发、故障与验证

所有管理写入携带当前数据库 revision，陈旧提交拒绝覆盖；编辑草稿保留，刷新核对后重新打开最新版本。读取按需分页，管理页轮询间隔 5 秒；切换会话、Agent 或取消请求后重新校验授权，排队旧写入不能落盘。

损坏或权限错误不创建空库替代。保留原文件，停止同一 DSH_HOME 的全部写入进程后，由维护者核对上一有效版本 `memory.json.bak` 再离线恢复；恢复边界见[闭环指南](closure-2026-11-01.md#配置与记忆恢复)。当前管理页不提供在线全库回滚或安全擦除。

回归入口为 `tests/memory-management.test.mjs`、`tests/memory-tool.test.mjs`；`tests/ui.acceptance.mjs` 使用真实本地 DSH 控件、独立浏览器及临时数据，验证新增、确认、修订、暂停恢复的真实召回结果、版本历史、分页、JSON 下载、批量遗忘与共享隔离。它不接管宿主浏览器，不调用付费模型。最终运行结果见[机器报告](checks/closure-2026-11-01.json)。
