# 代码任务营销口径

## 题集质量口径

> Patchwork Coding Task Benchmark 的 8 道代码维护题都有独立工作区、公开回归测试、隐藏
> 验收和参考修复；本次题集质量验证 8/8 通过，说明每道题可复现、基线会失败、参考修复
> 能通过隐藏验收。

可公开的数据点（题集版本 `0.1.0`，run id `coding-oracle-2026-10-31`）：

| 指标 | 结果 | 说明 |
|---|---:|---|
| 代码维护题 | 8 | retry、路径边界、脱敏、稳定排序、JSONL 恢复、记忆 CAS、任务状态、搜索去重 |
| oracle 题集质量 | 8/8（100%） | 8 个有 bug 的基线均失败，8 个参考修复均通过公开与隐藏测试 |
| 主 DSH 修改 | 0 | 每题使用独立临时工作区；oracle 运行不启动主 DSH |

这组数字可以营销“题集可复现、验收覆盖隐藏回归”，不能营销成 Agent 完成率。

## 真实 Agent 口径

只有在真实 Patchwork Agent 运行后，才可以使用：

> Patchwork 在固定版本的 8 道代码维护任务中完成 X/8，隐藏测试通过率 Y%，中位改动 Z 行；
> 每题都在独立 DSH 工作区执行，完整结果包含模型、DSH 版本和 run id。

不能把 `oracleTaskQualityRate` 写成 Agent 完成率，也不能只展示公开测试通过而隐藏失败。

真实 Agent 运行报告必须追加同一题集版本下的模型、DSH 版本、隔离 `DSH_HOME`、工作区快照、
每题隐藏测试输出、请求数、耗时、改动文件/行数和 run id。当前没有这组新题的真实 Agent
完成率，因此对外材料应保留 `agentTaskPassRate: pending`，不要填 0 或推测值。
