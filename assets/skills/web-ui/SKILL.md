# Web / UI 设计

1. **层级**：一屏一个主操作；其余降 1–2 级。
2. **对比**：主/次按钮必须在填充、描边或字重上可区分。
3. **密度**：列表默认密；营销页才大留白。不要默认「卡片+圆角+紫渐变」。

- 组件边界对齐业务角色，不对齐工具类名。
- 主操作全产品一种视觉语言；先网格/流式，再微调间距。
- 避免三等分特性列 + 居中大标题 + 双按钮 的默认落地页，除非用户要模板。
- 状态不要只靠颜色（补图标或文案）。
- 改后走关键路径或截图对比；可访问性不过先修可用性。
