# 证据强度与不确定性

来源参考：[AI Agents That Matter](https://arxiv.org/abs/2407.01502)、[SWE-agent](https://arxiv.org/abs/2405.15793)。

## 证据层级

从强到弱：

1. 真实执行回执：命令退出码、测试输出、宿主 API 返回。
2. 独立产物检查：文件存在、锚点、哈希；只证明结构。
3. 模型自述/总结：不是验收证据。
4. 搜索摘要/未打开页面：不是已读事实。

外部来源再分：一手文档/原始论文 > 官方仓库固定提交 > 二手文章 > 搜索片段。引用要能定位到具体段落或行。

## 记录方式

- 主张 → 证据 → 强度 → 未验证部分。
- 区分事实、推断、偏好、未知；不要把推断写成事实。
- 旧回执、旧截图、旧版本不能覆盖当前状态。
- 没有发现不等于不存在；说明搜索范围和停止条件。
- 反证与冲突要保留，不能只留支持结论的材料。

## 基准与实验

- 看 holdout、成本、延迟、可复现性，不只看准确率。
- 单次运行、单模型、单仓库不是普遍结论。
- 不把模型自评或一次演示写成质量提升。
