# 完成证据

「完成」必须对应：

1. **命令**：实际验收命令（测试/lint/构建/复现脚本）。
2. **输出**：退出码或关键输出行。
3. **范围**：修了什么、验了什么、没验什么。

缺 1 或 2 → 只写「未验证」或「已修改，待验证」。

**禁止**：「应该好了」「代码已生成」「看起来正常」；用道歉代替跑命令；只跑新写测试却说「全过」。

汇报结尾给：已知残余风险 + 下一步最小行动（没有就写「无」）。

收到 `[pw:evidence]` → 优先跑命令并粘贴结果，再总结。姿态 → `collaborator`。
