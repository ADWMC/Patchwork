# 实验准入

候选要有真实 incident id、来源回执、可观察触发、预期行为和回退对象。调优任务只能用于修改候选；留出任务在规则冻结后评测。使用相同模型、宿主、工具、任务快照和预算比较，记录失败样本，不只展示最好的一次。

分别报告路由、参考读取、工具流程、产物验收、token/耗时及非 Patchwork 会话可见性。机器 oracle 可验可重复行为和权限；视觉、写作与用户体验要有事先定义的评审尺度。成本没有测量就保持未知。

`scripts/check-evolution.mjs` 是离线档案形状检查，不能签发运行时证据。当前运行时 `experiment` 使用固定受限策略契约，在两个干净环境的子进程中执行 baseline/candidate 与留出检查，签发文件 SHA256 并在确认时重验。`trial/approve` 经用户确认后实际应用本会话策略，`rollback` 恢复此前版本；均不会改写技能文件或发行代码。契约输出只证明行为、隔离和类型，不证明模型收益；模型质量、请求数、成本未实测时明确保持未知。

## 从纠正到候选

保留失败或纠正的任务输入、当前规则版本、可观察错误、用户期望与最小脱敏回执。候选只改一个可描述的行为，例如“读到足以回答的官方原文后停止检索”；写出适用条件、排除条件和如何回退。若没有真实回执或反例，先收集证据，不伪造 incident。

| 比较轴 | 至少观察什么 | 不能用什么替代 |
| --- | --- | --- |
| 正确性 | 预先确定的任务验收与失败样本 | 模型自称完成 |
| 路由与读取 | 实际技能调用、参考文件读取、相邻负例 | 目录中存在该技能 |
| 成本 | 请求、token、工具调用、耗时与失败重试 | 单次最快样本 |
| 隔离 | 非 Patchwork 会话、切换后旧引用、持久数据范围 | 只测当前会话能用 |

在相同任务快照、模型、工具版本和预算下至少比较无技能、当前基线、候选与等长无关文本。调优集用于改规则；规则冻结后用留出集看是否泛化，记录每次运行而非只报成功样例。外部网络、缓存和随机性无法固定时，把这部分成本差异标为不确定。

发现权限越界、关键任务退化或用户确认缺失时停止采用，保留可回退版本。候选的 `trial/approve/rollback` 是受控状态转换，不因评测表填满而自动生效；最终决定由当前宿主确认通道和用户作出。
